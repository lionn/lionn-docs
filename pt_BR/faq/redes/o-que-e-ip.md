# O que é IP?
O IP (Internet Protocol), é um protocolo essencial na comunicação de redes, responsável pelo endereçamento e roteamento de pacotes de dados entre dispositivos na Internet e redes privadas. O IP assegura que os dados enviados de um dispositivo cheguem ao dispositivo correto na rede.


---


## Função do IP

A principal função do IP é:

Endereçamento: O IP atribui endereços únicos a cada dispositivo em uma rede. Esse endereço IP é usado para identificar e localizar o dispositivo na rede.
Roteamento: O IP determina o caminho que os pacotes de dados devem seguir para chegar ao destino. Ele faz isso encaminhando os pacotes através de roteadores e redes intermediárias.


---


## Versões do IP

Existem duas versões principais do IP:

IPv4 (Internet Protocol version 4): A versão mais antiga e amplamente utilizada do IP, que usa endereços de 32 bits, permitindo cerca de 4 bilhões de endereços únicos. Devido ao crescimento da Internet, o IPv4 está começando a se esgotar.
IPv6 (Internet Protocol version 6): Introduzido para resolver a limitação de endereços do IPv4, o IPv6 usa endereços de 128 bits, oferecendo um número muito maior de endereços únicos e uma melhor eficiência no roteamento.


---


## Importância do IP
O IP é fundamental para:

Permitir a comunicação entre dispositivos em redes locais e na Internet.
Fornecer um sistema de endereçamento que possibilita a identificação e localização de dispositivos.
Facilitar o roteamento de pacotes de dados através de redes complexas e diversos roteadores.
O IP é a base da comunicação na Internet e em redes privadas, possibilitando que os dados sejam corretamente encaminhados e entregues aos dispositivos apropriados.
